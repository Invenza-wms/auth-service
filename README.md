# Invenza_ForgetPassordPortal

## How to run
1. Install dependencies: `npm install` or `yarn`
2. Start dev server: `npm run dev`
3. Open the shown localhost URL (usually http://localhost:5173)

This is a minimal Vite + React + TypeScript project containing the "Forgot Password" flow:
- Enter Email/Mobile -> Send OTP -> Verify OTP -> Reset Password -> Success
- Password validation: contains at least 1 uppercase, 1 special char, 1 number, and maximum length 8.
